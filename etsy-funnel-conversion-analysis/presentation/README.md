# Etsy Funnel Analysis - Presentation Deck

This folder contains the executive presentation summarizing key findings and strategic recommendations from the Etsy Funnel Analysis project, crafted specifically for **hiring managers and business stakeholders**.

The deck translates analytical insights using [SQL based funnel insights](https://github.com/ashishkumar-ds/data-science-projects/blob/main/etsy-funnel-conversion-analysis%2Fnotebooks%2FREADME.md) into a clear, action-oriented narrative, highlighting a **90% cart abandonment rate**, critical friction points in checkout and payment, and prioritized opportunities to **increase conversion by 5% in Q1 2023**.

No technical jargon. Just business impact.
